# Animaciones Lottie

Aquí van los JSON exportados desde After Effects (Bodymovin) o LottieFiles.

Usos previstos:

- reacción de los personajes al acertar o fallar
- efecto de victoria al final de la partida
- decoración del menú principal

Reglas: sólo animaciones propias o con licencia libre. GSAP se encarga de las
transiciones de interfaz; Lottie sólo de las piezas ilustradas.
